# Hardware roadmap

v0 prototype: focus on durability and battery life. Evaluate modules and keep part numbers as example options to evaluate.

Key subsystems
- GNSS module
- Ultra-low-power MCU
- LTE-M / NB-IoT / LoRaWAN modem (evaluate coverage)
- Speaker / buzzer
- Pulse driver circuit with current/voltage limits and watchdog
- IMU (accelerometer + gyro)
- Temperature trend sensor
- Battery + optional solar
- Rugged waterproof enclosure

Production considerations
- RF certification, animal safety testing, enclosure sealing, manufacturing test fixtures.
