# Pilot scorecard

Containment metrics
- Boundary compliance %
- Escapes / week
- Time outside geofence (aggregate)
- Training completion time
- Audio cues per animal / day
- Pulse events per animal / day
- Cue-to-pulse ratio

Operations
- Labour hours saved / week
- Fencing time reduced
- Herding time reduced
- Time to locate animal
- Estimated € saved vs physical fencing
- Farmer satisfaction score

Hardware
- Battery life
- GPS accuracy
- Connectivity uptime
- Device failures

Health monitoring
- Activity deviation flags
- Temperature trend flags
- Movement anomaly candidates
