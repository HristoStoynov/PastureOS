# Product Specification — PastureOS (v0)

Goal: build a safe, auditable collar + cloud platform to contain cattle using virtual geofences and provide actionable pilot metrics.

Core capabilities (v0):
- GPS tracking and live location
- Virtual fences with warning zones
- Audio cue followed by controlled, limited pulse only after warning
- Live dashboard with map and event timeline
- Event logging and pilot scorecard export
- Battery & connectivity monitoring
- Farmer override / pause mode

Non-goals for v0: diagnostic AI, multi-species, manufacturing certification.
