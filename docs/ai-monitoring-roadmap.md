# AI & Monitoring Roadmap

Phase 0
- Rule-based alerts and pilot logging only.

Phase 1
- Per-animal baselines, rolling average, z-score anomalies, simple thresholds.

Phase 2
- Vet-labelled datasets, supervised models for classification of anomaly candidates.

Phase 3
- Confidence-aware alerts, priority queues, feedback loop with vets, human-in-the-loop review.

Notes
- AI is non-diagnostic — output must be suggestions and candidate flags for human/vet review only.
