# Pilot plan (12 weeks)

Week 0–1
- Sign pilot agreement and safety approvals
- Baseline farm ops, map pastures, select animals
- Confirm connectivity and power planning

Week 1–4
- Build MVP collars and dashboard
- Bench test GPS, audio, pulse circuit, battery
- Simulate geofence logic in lab
- Define training protocol for animals

Week 5–8
- Deploy controlled field pilot with training mode
- Track cue/pulse ratio and containment metrics
- Weekly farmer feedback and iterative fixes

Week 8–12
- Evaluate containment, labour savings, and battery
- Produce pilot scorecard and recommendations
- Decide on V1 rollout readiness
